# RRF Website — GitHub Pages

## Files
- `index.html` — complete responsive one-page website.
- `assets/` — RRF logo and gallery images.

## Publish on GitHub Pages
1. Create/open a GitHub repository.
2. Upload `index.html` and the entire `assets` folder.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select your main branch and `/ (root)`.
5. Save and wait for GitHub Pages to publish.

The website uses only HTML, CSS and JavaScript, so no build process is required.
